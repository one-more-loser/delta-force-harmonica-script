# 贡献指南

先阅读 HANDOFF.MD。使用 Windows x64、.NET 8 SDK、PowerShell 7；用统一 Build.ps1 入口构建、测试和发布。

修改输入、调度、取消、媒体或文件清理时，提供有行为断言的离线复现；默认使用输入替身和隔离数据，不向游戏或其他用户窗口发送真实输入。验证新增等待点、held状态、资源释放和异常路径。

请勿提交个人曲库、设置、日志、API密钥、完整运行时、构建缓存或机器绝对路径。曲谱需明确来源与分发权。不要加入驱动、注入、ACE修改、反检测或免封宣传。

提交说明应区分构建检查、离线行为和人工游戏观察；性能变化提供相同规模、预热与GC说明。发布到新目录，保留运行时许可证并核对自包含配置。
