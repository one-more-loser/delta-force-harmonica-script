# 故障排查

## 提示安装 .NET，但已经安装

先区分普通构建与自包含发布。普通 Build 需要 .NET 8 Desktop Runtime x64；Publish 携带完整运行时。历史故障是将依赖系统框架的 runtimeconfig.json 覆盖到带本地 hostfxr/coreclr 的包中。不要反复安装运行时或盲目重启，先核对 host 跟踪和发布配置；重新发布到全新目录通常更容易保持包一致。

## “准备演奏”不可点击

检查曲目是否可编排、是否有操作未结束、热键是否注册成功、是否仍有按键释放失败。F8 已占用时可选其他热键。历史界面中热键错误提示可能被后续选曲/试听提示覆盖；提示覆盖问题尚未修复。

## 目标窗口失去焦点

目标游戏不再是前台窗口即停止。切回工具或截图工具也可能触发；回到游戏后重新按热键，不会自动续播。倒计时结束时须核对实际前台窗口，而不是只确认屏幕仍可看见游戏。

## 微信能收到输入，游戏没反应

仅能证明普通窗口的输入链路有效。记录目标句柄/类名、进程权限、是否保持前台、游戏音键是否高亮以及手动按键是否有声。历史现场发现游戏高完整性、演奏器普通完整性，尚未完成同权限对照；不能把权限、输入法或 ACE 中任何一项称为已确认唯一根因。

本项目不提供绕过游戏输入限制或反作弊的方法。日志的“发送N个事件”不等于游戏已消费输入。

## 试听残留 WAV

新文件位于用户数据目录的 previews-v1，严格会话/文件GUID命名。旧根目录WAV因归属不明保留。持续锁定、近期孤儿或超出批次预算的文件可能延期；进程退出后没有后台删除者。不要扩大删除模式去追求零残留。
