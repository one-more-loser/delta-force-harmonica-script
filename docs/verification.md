# 验证范围

核心测试会验证解析、编排、停止、失焦、失败释放、x64 INPUT及其他边界；部分既有 RegressionTests 仍是源码字符串断言或独立计时，不能将它们等同于真实生命周期测试。

桌面测试通过安全副本运行真实 WPF 方法和文件锁，默认真实输入被替换为抛错实现，数据和曲库隔离。覆盖最终轨数边界、文件归属、UI清理响应、64项pending溢出恢复、批次锁、试听/关闭、路径创建失败以及初始化关闭交错。

2026-10-20的历史修复验收记录：原核心测试27/27（含私人88曲库检查）、既有回归11/11、桌面组19/19。预热5轮后30轮试听取消及10窗关闭，WAV残留0、窗口弱引用存活0；这些历史数字不等于本次新结构的执行结果，也不是长期无泄漏证明。公开仓库只有一个自有示例。

本次目录整理的实际命令、退出码及包一致性结果由维护者记录在 HANDOFF.MD。性能验收关注没有新增生产任务、程序集及轮询；部署包采用全新目录和完整运行时，不混用构建产物。

未验证：游戏实际输入消费、ACE策略与处罚、8小时运行、所有磁盘/ACL故障。API成功、CI通过、内存短时平稳和发布包能启动均不能替代这些验证。
